# Third Party Fonts

## ONE Mobile POP

- File: `ONE-Mobile-POP.ttf`
- Source: https://www.onestorecorp.com/sv/fordev_font/
- Use in project: primary UI font.
- License note: official ONE store font page allows use in print, web, video, package, embedded app, BI/CI, and commercial/non-commercial works. Do not sell the font file itself.

## Jalnan2

- File: `Jalnan2.ttf`
- Source: https://gccompany.co.kr/font
- Use in project: title, stage, boss, and major header text.
- License note: GC Company font page allows personal and commercial use, including print, web, video, app/game embedding, BI/CI, and OFL redistribution. Keep source/license info for release review.

## Jua

- File: `Jua-Regular.ttf`
- Source: https://fonts.google.com/specimen/Jua
- Use in project: fallback font.
- License note: SIL Open Font License. Existing project fallback.

## MapleStory Font

- File: `Maplestory Light.ttf`
- File: `Maplestory Bold.ttf`
- Source: https://maplestory.nexon.com/Media/Font
- Use in project: primary UI, title, button, and damage number font.
- License note: official MapleStory font page says the font is free for all users, can be used and distributed freely, can be bundled or used as an embedded font with the copyright notice included, cannot be modified/edited, cannot be sold as the font itself, and source attribution is recommended.
