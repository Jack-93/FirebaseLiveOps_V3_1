# Kenney Icon Subset

This folder contains a curated subset of CC0 Kenney icon packs for prototype UI.

## Included Packs

- Game Icons: https://kenney.nl/assets/game-icons
- Board Game Icons: https://kenney.nl/assets/board-game-icons

## Usage

- `Game/`: common action icons such as home, gear, plus, star, trophy, save, and checkmark.
- `Board/`: RPG/menu/resource icons such as sword, shield, skull, crown, cards, pouch, and character.

Only selected PNG files are copied into the Unity project to avoid importing the full downloaded packs.
