# World Story Guide

## 핵심 콘셉트

- 장르: 2D 모바일 방치형 RPG
- 분위기: 귀엽고 둥근 픽셀 아트, 밝은 색감, 작은 캐릭터 실루엣
- 주인공: 참새 이등병
- 적대 세력: 고양이
- 핵심 분쟁: 조류와 고양이가 각 동네의 전봇대를 두고 전쟁 중
- 전봇대의 의미: 조류들의 집, 쉼터, 삶의 터전

## 메인 스토리

이 세상 조류들은 고양이라는 동물과 전쟁 중이다.
전쟁의 이유는 각 동네의 전봇대를 차지하기 위해서다.
조류들에게 전봇대는 단순한 구조물이 아니라 살아갈 수 있는 터전이며,
고양이에게 빼앗기면 동네의 하늘과 보금자리를 잃게 된다.

플레이어는 참새 이등병이다.
전쟁 중 왼쪽 날개가 부러져 전방에서 직접 싸울 수는 없지만,
뒤에서 전력을 충전해 팀원들이 스킬을 사용할 수 있도록 돕는다.
플레이어의 성장은 직접 공격자가 강해지는 느낌보다는
부대 전체를 지원하고 스킬 운용 능력을 키우는 방향으로 확장한다.

## 튜토리얼 방향

- 신규 유저는 첫 플레이 진입 직후 스토리 튜토리얼을 본다.
- 튜토리얼은 5~7컷 정도의 만화 형식이다.
- 화면을 클릭하면 다음 컷으로 넘어간다.
- 컷씬 종료 후 현재 기능 튜토리얼로 이어진다.
- 모든 컷은 실제 아트가 들어오기 전까지 단색 배경과 `(아트 필요)` 문구로 대체한다.
- 현재 구현 상태: UI 틀, 컷 진행, 스킵, 저장 필드, 기존 기능 튜토리얼 연결 완료.
- 남은 작업: 컷별 최종 대사 확정, 실제 픽셀 아트 교체, 연출 효과 추가.

## 튜토리얼 컷 초안

1. 전봇대 위의 세상
   - 대사: 추후 확정
   - 아트: 평화로운 동네 전봇대 위에 작은 새들이 모여 있는 장면.

2. 고양이의 진격
   - 대사: 추후 확정
   - 아트: 골목 아래에서 고양이들이 전봇대를 올려다보는 장면.

3. 전봇대 쟁탈전
   - 대사: 추후 확정
   - 아트: 전봇대를 중심으로 새 부대와 고양이 부대가 대치하는 장면.

4. 참새 이등병
   - 대사: 추후 확정
   - 아트: 붕대를 감은 왼쪽 날개를 바라보는 작은 참새 병사.

5. 뒤에서 할 수 있는 일
   - 대사: 추후 확정
   - 아트: 발전기나 배터리 장치 앞에 서 있는 참새 이등병.

6. 스킬 충전
   - 대사: 추후 확정
   - 아트: 전기 에너지와 동료들의 스킬 게이지가 빛나는 장면.

7. 작전 개시
   - 대사: 추후 확정
   - 아트: 전봇대 위에 모인 조류 팀이 출격 준비를 하는 장면.

## 아트 레퍼런스 메모

첨부 이미지는 그림체 방향 참고용이다.
실제 게임 에셋은 저작권 문제가 없도록 오리지널 픽셀 아트로 제작한다.

핵심 키워드:

- 귀여운 도트
- 둥근 캐릭터
- 밝은 색감
- 작은 픽셀 UI
- 전기/충전 이펙트
- 새 부대와 고양이 부대의 장난감 같은 전쟁 분위기
